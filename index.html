Multer

Uploading files to a local public folder in Node.js using Multer involves a few steps. This article helps you set it up.

npm install multer

1. Connection Logic

Include express and multer in your server file.app.js
const multer = require('multer');


app.use(express.static('public'));
Create an folder for public.
Create an folder inside public for Images stor.
const storage = multer.diskStorage({
     destination: function (req, file, cb) {
          cb(null, 'public/uploads')
    },
   filename: function (req, file, cb) {
         cb(null, file.fieldname + '-' + Date.now())
   }
});

const upload = multer({ storage: storage });
'public/uploads' - change this and add your file name.

Create an Upload Route

Convert the schema into a usable model
app.post('/upload', upload.single('file'), uploas);
uploas- Enter your controller fuction name you need

Create a Form to Submit Files

Create an HTML form with action="/upload", method="post", and enctype="multipart/form-data".

<form action="/upload" method="post" enctype="multipart/form-data">
    <input type="file" name="file" />
    <input type="submit" value="Upload File" />
</form>

Local-Storage

node-localstorage is a drop-in substitute for the browser native localStorage API that runs on node.js.

Install local storage

npm install node-localstorage
Import node-localstoragecontroller.js 
import {LocalStorage} from "node-localstorage"

var localStorage = new LocalStorage('./scratch');

Stor data in to localstorage

Add this for insert datacontroller.js 
localStorage.setItem('Name', value)
get data into a varablecontroller.js
localStorage.getItem('Name')
